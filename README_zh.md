# 👗 Awesome Closet Stylist | 智能衣橱造型师

*你的私人 AI 造型师，了解你拥有的每一件衣服。*

一款高自主性智能体技能，帮助用户维护持久化的个人衣橱数据、回答衣橱相关问题，并根据现有衣物智能推荐每日穿搭。支持自然语言交互，无需复杂表单操作。

---

### ✨ 核心亮点

-   **👗 智能衣橱管理**：通过自然语言记录、更新和查询衣物信息，告别手动表单。
-   **🎯 场景化穿搭推荐**：结合天气、场合和风格偏好，从现有衣物中智能搭配每日造型。
-   **🧠 复合意图自主处理**：一个请求可包含多个意图（如记录+推荐），无需拆分为多轮对话。
-   **🔒 安全边界设计**：明确的事实/写入/确认/授权分层，确保状态变更安全可控。

---

### 🚀 快速开始

想要管理衣橱并获得穿搭建议，只需在对话框中输入：

> **"请启用 Awesome Closet Stylist 技能。帮我记录新买的蓝色牛仔外套（适合春秋季），然后根据明天北京的天气推荐一套穿搭。"**
