# 👗 Awesome Closet Stylist

*Your personal AI stylist who knows every piece of clothing you own.*

A high-autonomy agent skill that maintains a persistent personal wardrobe, answers wardrobe-related questions, and recommends outfits from your existing clothes — all through natural language conversation.

---

### ✨ Core Highlights

-   **👗 Smart Wardrobe Management**: Record, update, and query clothing items effortlessly through natural language — no forms or complex workflows.
-   **🎯 Context-Aware Recommendations**: Build outfits based on weather, occasion, and style preferences using only the items you actually own.
-   **🧠 Autonomous Intent Handling**: Handle compound requests (e.g., record + recommend) in a single turn without forcing rigid workflows.
-   **🔒 Safe-by-Design Boundaries**: Clear fact/write/confirmation/authorization layers ensure state changes are always safe and transparent.

---

### 🚀 Quick Start

> **"Please enable the Awesome Closet Stylist skill. I just bought a blue denim jacket (suitable for spring/fall). Record it and recommend an outfit for tomorrow's weather in Beijing."**
